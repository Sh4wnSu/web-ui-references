# Apple 风格图标
参考苹果原生符号的光学对齐、圆端点、统一线宽与语义。建议 16/20/24px，线宽 1.5–2px；图标按钮提供可访问名称。不分发 Apple 专有图标资产。

## Account action icons
[Sign out](../../assets/icons/account/sign-out.svg) · [Circle variant](../../assets/icons/account/sign-out-circle.svg) · [Door variant](../../assets/icons/account/sign-out-door.svg) · [Sign in](../../assets/icons/account/sign-in.svg). Original 24×24 glyphs, 1.8px round strokes, currentColor. Prefer sign-out in account menus; use a text label, not color alone. Do not confuse sign out with closing a window or quitting an app.
