# advanced-interactions
Apple 风格组件分类。统一系统字体、中性色、语义强调色、柔和圆角、克制动效及可见焦点。
[内部示例](../../examples/ui-system/index.html#advanced-interactions)（仅覆盖部分条目）。

|组件|用途|
|---|---|
|Draggable Sheet|拖拽面板|
|Spotlight|全局搜索|
|Drag and Drop|拖放|
|Shared Element|共享元素|
|Swipe Actions|滑动操作|
|Floating Window|浮动窗口|
|Rubber Band|橡皮筋|
|Inertia|惯性|
