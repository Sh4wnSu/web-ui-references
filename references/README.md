## 风格对比
|维度|Apple|Material|Fluent|极简 SaaS|
|---|---|---|---|---|
|字体|SF Pro|Roboto|Segoe UI|Inter/Geist|
|圆角|连续|分级|柔和|常规|
|颜色|中性|动态主题|中性强调|黑白灰|
|材质|Glass|色调表面|Acrylic/Mica|实色|
|动效|弹性|容器转换|缓动|快速反馈|
专业工具建议 macOS 分栏 + Linear 信息密度 + Apple 卡片和排版，概览用 Bento，玻璃仅控制层。优先字体、空间、配色、组件一致性，再做圆角、图标、动效、阴影、玻璃。
