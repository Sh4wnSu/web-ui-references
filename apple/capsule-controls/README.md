# Apple-inspired Capsule Controls
独立胶囊滑块（segmented control / sliding indicator），区别于仅切换选中背景的 Tabs。用于周期、模型、主题、筛选和视图选择；页面导航使用链接，面板切换使用 tab 语义，互斥设置使用 radio 语义。
