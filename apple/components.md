# 组件、导航、图标
|组件|设计原则|
|---|---|
|Button|实色主操作、次级填充、描边、文本；胶囊或连续角|
|Input|浅填充、弱边框、明确焦点|
|Search|图标、占位符、快捷键|
|Switch|胶囊轨道、白色滑块、明确状态|
|Segmented|共享轨道、选中块|
|Checkbox|清晰勾选|
|Slider|细轨道、圆滑块|
|Badge|低饱和紧凑|
|Dropdown|浮动表面、勾号、柔和阴影|
|Dialog|聚焦主要操作、支持 Esc|
|Tooltip|紧凑靠近目标|
|Toast|非阻塞简短反馈|
|Progress|简洁轨道|
|Skeleton|匹配真实布局|
顶部导航适合官网；桌面侧边栏适合工作台；移动悬浮导航适合少量核心入口。选中填充、文字和图标表达当前位置。
图标统一视口、圆端点、光学对齐；小 14–16、普通 18–20、导航 20–24、大 28–32px；描边 1.5–2px。SF Symbols 有授权限制。
控件高度参考 40px，触控命中区域建议 44×44 CSS px。
