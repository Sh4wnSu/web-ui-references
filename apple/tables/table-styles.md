# 十二种表格
|样式|视觉特征|用途|
|---|---|---|
|A macOS striped|交替浅灰行、弱边框|文件、资源|
|B minimal|细横线、白底|分析|
|C card|圆角容器、浅表头|SaaS|
|D dense|紧凑行高、数字对齐|性能监控|
|E dark|深色弱网格|开发工具|
|F glass|半透明、背景模糊、边缘高光|小型浮动面板|
|G status|低色度状态标签、文字与色点|服务状态|
|H progress|行内进度条与数值|配额、任务|
|I sparkline|行内趋势线|历史性能|
|J outline|层级缩进、展开按钮|资源树|
|K grouped|圆角分组键值列表|设置|
|L Numbers report|主题表头、汇总行|账单报表|
玻璃仅适用于少量数据，长时间阅读优先实色。
