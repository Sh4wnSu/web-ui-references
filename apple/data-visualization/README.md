# Apple-inspired Data Visualization
本专题整合苹果 Dashboard 设计与统计图表分类。所有推荐参数均为 Web 设计建议，不是苹果官方固定规范。
## 官方应用参考
|应用|值得研究的图表与设计|
|---|---|
|Health|大数字、周期分段控件、右侧轴、柱状/区间/散点/折线、平均线、触摸选点|
|Fitness|黑底、语义高辨识色、活动环、心率区间、目标进度|
|Screen Time|堆叠柱、分类排名、平均线、水平占比|
|Battery|密集细柱、事件标记、共享时间轴、状态时间线|
|Weather|渐变区间条、当前/最小/最大值、预测、环境色卡片|
|Stocks|折线、面积、Sparkline、周期切换、定位线、涨跌色|
|Storage|横向容量组成条|
|App Store Connect|桌面业务分析、筛选、多指标、周期比较、表格|
|Maps|地理空间可视化|
