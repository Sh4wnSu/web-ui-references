# Continuous corner geometry
The entire account trigger is selected while its menu is open. Use the same continuous-looking rounded-rectangle mask for hover, press, expanded background and focus outline. The popup has its own larger radius (16px); menu rows use smaller 9px corners with 6px inset, approximately concentric. Do not use square row highlights, disconnected selection patches or clipped focus rings. The gallery generates responsive cubic Bézier SVG paths in normalized coordinates from actual width, height and radius; CSS clip-path uses an SVG path, with border-radius fallback. This is an independent approximation, not Apple’s exact G2 curve. Popup is anchored above the footer, clamped to viewport, outside sidebar clipping; use a disclosure button with aria-expanded, ordinary buttons, Escape/outside dismissal and focus restoration. Destructive action separated by a divider.
