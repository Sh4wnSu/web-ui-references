# glass-cards
Apple 风格组件分类。统一系统字体、中性色、语义强调色、柔和圆角、克制动效及可见焦点。
[内部示例](../../examples/ui-system/index.html#glass-cards)（仅覆盖部分条目）。

|组件|用途|
|---|---|
|Frosted Card|经典毛玻璃|
|Liquid Card|液态玻璃|
|Adaptive Tint|环境染色|
|Spatial Card|空间悬浮|
|Bento Glass|组合卡片|
|Dark Glass|深色|
|Interactive Glass|交互高光|
|Popover Card|气泡卡片|
