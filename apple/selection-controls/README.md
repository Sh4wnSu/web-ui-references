# selection-controls
Apple 风格组件分类。统一系统字体、中性色、语义强调色、柔和圆角、克制动效及可见焦点。
[内部示例](../../examples/ui-system/index.html#selection-controls)（仅覆盖部分条目）。

|组件|用途|
|---|---|
|Switch|开关|
|Checkbox|复选|
|Radio|单选|
|Slider|数值滑杆|
|Range Slider|双端区间|
|Stepper|步进|
|Select|下拉|
|Combobox|组合框|
|Date Picker|日期|
|Time Picker|时间|
|Color Picker|颜色|
|Rating|评分|
