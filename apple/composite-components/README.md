# composite-components
Apple 风格组件分类。统一系统字体、中性色、语义强调色、柔和圆角、克制动效及可见焦点。
[内部示例](../../examples/ui-system/index.html#composite-components)（仅覆盖部分条目）。

|组件|用途|
|---|---|
|Settings|设置|
|Chat|聊天|
|Composer|输入区|
|Markdown|流式文本|
|Media Player|播放器|
|Authentication|登录|
|File Manager|文件管理|
|Upload|上传|
|Calendar|日历|
|Canvas|画布|
|Node Editor|节点|
|Inbox|收件箱|
|Code Editor|代码|
|Terminal|终端|
|Cropper|裁剪|
|Kanban|看板|
